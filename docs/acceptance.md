## 基本验收

| 操作或输入 | 预期现象 |
|---|---|
| 使用默认参数开始 | 从位移 0.20 m 静止释放，先往平衡点运动，振幅逐渐减小 |
| 经过平衡点和振动转折点 | 仿真继续运行 |
| 暂停，再继续 | 暂停期间时间和位移保持，继续从暂停点推进 |
| 修改参数后复位 | 时间归零，位置回到新初始位移，速度为零 |
| 输入非法数值 | 应显示参数错误，保留原有模拟状态 |
| 运行到静止 | 进入静止状态，再等待时模拟时间保持不变 |

## 打包运行

```powershell
.\gradlew.bat :simulation-core:test :desktopApp:packageUberJarForCurrentOS
Get-ChildItem .\desktopApp\build\compose\jars\*.jar
```

将生成的 JAR 拷到目标机，确认 `java -version` 显示 JDK 21 后，用 `java -jar "实际文件名.jar"` 启动。该 JAR 包含当前系统和架构对应的依赖。[Compose 桌面打包文档](https://kotlinlang.org/docs/multiplatform/compose-native-distribution.html)
